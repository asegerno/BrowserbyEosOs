# BrowserbyEosOs

EosOs 現代主流網頁瀏覽器整合發行包與安裝資源庫 (Modern Web Browsers Collection for EosOs).

---

## 📌 簡介 (Introduction)
本倉庫整合收錄當前主流的多款 Chromium 與 Gecko 內核網頁瀏覽器，專為自定義系統與工作環境提供快速安裝與配置參考。

---

## 🌐 收錄瀏覽器目錄與授權屬性 (Browsers)
* **[Google Chrome](./Chrome)**：全球主流 Chromium 內核標準瀏覽器 (專有軟體 / Proprietary Freeware)
* **[Microsoft Edge](./Edge)**：微軟官方內建瀏覽器 (專有軟體 / Microsoft EULA)
* **[Mozilla Firefox](./Firefox)**：開源 Gecko 內核隱私瀏覽器 (MPL 2.0 開源協議)
* **[Brave Browser](./Brave)**：廣告攔截隱私瀏覽器 (MPL 2.0 / Chromium 混合授權)
