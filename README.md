# BrowserbyEosOs

EosOs 現代主流網頁瀏覽器整合發行包與安裝資源庫 (Modern Web Browsers Collection for EosOs).

---

## 📌 簡介 (Introduction)
本倉庫整合收錄當前主流的多款 Chromium 與 Gecko 內核網頁瀏覽器，專為自定義系統與工作環境提供快速安裝與配置參考。

---

## 🌐 收錄瀏覽器目錄 (Browsers)
* **[Google Chrome](./Chrome)**：全球主流 Chromium 內核標準瀏覽器
* **[Microsoft Edge](./Edge)**：微軟深度整合 Copilot 與現代效率工具之瀏覽器
* **[Mozilla Firefox](./Firefox)**：獨立 Gecko 內核、開源且高度保護隱私的經典瀏覽器
* **[Brave Browser](./Brave)**：預設內建廣告攔截、反追蹤與 Web3 特性之隱私極致瀏覽器
